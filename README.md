# RETINA-LAB — Deslocamento da Retina

Site escolar interativo sobre deslocamento da retina, conectando **Tecnociência, Robótica e Programação**.

## Principais partes

- olho que acompanha o cursor;
- exploração anatômica;
- laboratório de óptica e refração;
- mapa interativo da retina e campo visual;
- proposta de protótipo com sensores;
- 8 flashcards interativos;
- RETINA//EXAM com 10 questões em formatos diferentes;
- suporte opcional a Supabase e correção de respostas longas por IA.

## Abrir o projeto

Abra `index.html` em um servidor local ou publique o repositório no GitHub Pages.

Para recompilar os arquivos TypeScript:

```bash
npm install
npm run build
```

A configuração opcional do banco e da IA está em `SETUP-SUPABASE.md`.
